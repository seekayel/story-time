# Development: vision, characters, seasons, plots

## Vision — `story/vision.md`

Turn `story/brief.md` into a bible every later stage can lean on:

- one-sentence hook and the engine that keeps generating episodes;
- audience promise, tone, genre, themes, the feeling a listener should leave with;
- world rules, recurring locations, where stories come from, what never happens;
- episode format and continuity model (how standalone vs. serialized);
- content boundaries and representation notes;
- audio identity: narrator stance, sonic palette, dialogue density, music;
- canon rules, plus a short test for whether a pitched episode belongs in the show.

Make decisive creative choices and state them as facts about the show.

## Characters — `story/characters/<kebab-name>.md`

One file per recurring character, starting with `# Name` (this exact name is what scripts and the voice cast use). Cover:

- dramatic function and first-listen impression;
- want, need, flaw, fear, strengths, contradictions, secrets;
- backstory only where it drives present choices;
- relationships and tensions with the rest of the ensemble;
- **Voice on the page:** speech rhythm, vocabulary, humor, verbal tics, what they'd never say;
- **Casting notes:** perceived age, gender presentation of the voice, energy, pitch, texture, accent constraints, range — written so they can be matched against ElevenLabs voice labels;
- arc potential, hard boundaries, continuity facts.

Design the ensemble so every voice is distinct in function and in sound. Don't assign sensitive identity traits without a story reason or user direction.

## Season — `story/season-NN/arc.md`

- season thesis, central dramatic question, start state, end state, the irreversible change;
- A and B storylines and each main character's arc: setup, escalation, midpoint, crisis, climax, payoff;
- an episode grid with exactly the number of episodes the brief specifies. Per episode: title, hook, main conflict, character turn, arc movement, setups/payoffs, ending state;
- continuity ledger, planted elements, open questions, production risks (new voices needed, heavy SFX).

Avoid interchangeable premises. Each episode should cause something the next one inherits.

## Plot — `story/season-NN/episode-EE/plot.md`

Write against that episode's slot in `arc.md`. Include: logline, listener promise, what continuity it inherits, sequence-by-sequence beats, character turns, reveals, sound opportunities, resolution, arc movement, and what continuity it hands forward.

Check neighboring episodes for repeated locations, emotional shapes, villains, reveals, and solutions. A plot is ready to script when the protagonists' choices cause the major turns and the ending changes something.
